Como usar este modelo

1) Para criar um indicador novo, copie uma <section data-pag="..."> da página de exemplo.
2) Registre a página na lista PAGINAS no final do arquivo (id, nome, grupo e ícone).
3) As cores ficam em :root no CSS (vinho --accent). Troque ali para mudar o tema inteiro.
